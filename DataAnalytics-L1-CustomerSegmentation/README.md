# Customer Segmentation Analysis

## Objective

Segment customers based on their purchasing behaviour using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Analysis Performed

- Data inspection
- Data cleaning and preprocessing
- RFM analysis
- Recency calculation
- Frequency calculation
- Monetary value calculation
- RFM scoring
- Feature scaling
- Elbow Method
- K-Means clustering
- Cluster visualization
- Customer segment profiling
- Business recommendations

## Dataset

The dataset used for this task is large in size and therefore cannot be uploaded to this GitHub repository.

The dataset was used locally for the analysis and customer segmentation process.

## Key Insights

Insights will be added after completing the analysis.

## Conclusion

RFM analysis and K-Means clustering help identify different customer segments based on their purchasing behaviour and provide useful insights for targeted marketing strategies.
