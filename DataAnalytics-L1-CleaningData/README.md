# Cleaning Data

## Objective

Clean and prepare a messy dataset for analysis by identifying and handling common data-quality issues.

## Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning Performed

- Data inspection
- Missing-value analysis
- Duplicate detection and removal
- Inconsistent formatting correction
- Data type correction
- Outlier identification and treatment
- Data validation
- Before-and-after comparison

## Dataset

The dataset used for this task is cleaned systematically to make it suitable for further analysis.
